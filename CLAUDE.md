# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Context

This is a **research and documentation repository** for Team Selling ClawFriend competing in the **Cook A Web3 Skill Marketplace** competition. There is no code to build, test, or run — all content is Markdown research deliverables written in Vietnamese.

**ClawFriend** is a Web3 Skill Marketplace where AI agent skills are gated by token/share holdings (holder-gated model). Creators earn when holders access their skills.

## Repository Structure

| File | Deliverable | Weight |
|------|-------------|--------|
| `competitive-landscape.md` | Analysis of 7 Web3 AI Agent / Skill Marketplace competitors | 25% |
| `skill-research.md` | Research on 10 skills the platform should offer, with demand evidence | 25% |

## Content Conventions

**Language:** All deliverable content is in Vietnamese. Maintain this when editing.

**Numbers must have sources:** Every statistic in the deliverables must have a verifiable source (website, GitHub, on-chain data). Unsourced AI-generated numbers are explicitly called out as a disqualification risk (`"AI cho em" = trừ điểm`).

**Document structure:** Each deliverable uses consistent table-based formatting — each competitor/skill/channel is presented as a Markdown table with standardized fields.

**Competitor analysis fields:** Tên, Link, Mô tả, User/Download/GMV, Monetization, Điểm mạnh, Điểm yếu thực sự, Đang build gì?

**Skill research fields:** Tên skill, Target user, Problem, Alternative hiện tại, Skill giải quyết thế nào, Visibility & Monetization, Bằng chứng demand

**Distribution channel fields:** Loại (Organic/Paid), Tại sao chọn?, Action plan, Timeline, Estimated reach, Cost, Metric đo kết quả, Risk & Contingency

## Key Business Concepts

- **Holder-gated skills:** Skills are unlocked by holding a minimum number of shares (e.g., "Min 100 share để unlock premium"). This is ClawFriend's core differentiation.
- **Supply-side cold start target:** ElizaOS plugin developers (5,300+ forks, ~zero monetization) are the primary acquisition target for skill creators.
- **Month 1 OKRs:** ≥50 skills live, ≥300 unique wallet connects, ≥100 skill transactions.
- **Budget:** $10,000 total — $4K KOLs, $2.5K Twitter Ads, $3K Skill Creator Incentives, $0.5K contingency.
