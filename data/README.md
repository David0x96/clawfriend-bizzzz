# Data

Đặt tại đây:

- **Số liệu** đã thu thập (user count, download, pricing, GMV…).
- **Chart / biểu đồ** dùng trong phân tích hoặc presentation.
- **Research data** (export từ Google Trends, Reddit, v.v.) nếu có.

Mọi số liệu dùng trong `competitive-landscape.md`, `skill-research.md`, `distribution-plan.md` nên có **nguồn rõ ràng**. Có thể trích dẫn file trong folder này.
